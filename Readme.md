### **2. Класс Student (Student.h / Student.cpp)**

#### **Члены класса:**
```cpp
private:
    string name;              // Имя студента
    int id;                   // Уникальный ID
    vector<double> grades;    // Список оценок (0-100)
    string course;            // Название курса
```

#### **Публичные методы:**
```cpp
public:
    // Конструкторы
    Student();                              // По умолчанию
    Student(int id, const string& name, const string& course);  // С параметрами
    
    // Геттеры
    int getId() const;
    string getName() const;
    string getCourse() const;
    const vector<double>& getGrades() const;
    
    // Работа с оценками
    void addGrade(double grade);            // Добавить оценку с валидацией (0-100)
    bool removeGrade(size_t index);         // Удалить оценку по индексу
    void clearGrades();                     // Очистить все оценки
    
    // Статистика
    double getAverage() const;              // Средний балл
    double getHighest() const;              // Максимальная оценка
    double getLowest() const;               // Минимальная оценка

    char getLetterGrade() const;            // A (90-100), B (80-89), C (70-79), D (60-69), F (<60)
    
    // Вывод информации
    void displayInfo() const;               // Полная информация о студенте
    void displayGrades() const;             // Только список оценок
```

#### **Дополнительно:**
- Перегрузка оператора `<<` для удобного вывода
- Валидация: имя не пустое, ID > 0, оценки 0-100

### **4. Главное меню (main.cpp)**

```
=====================================
   СИСТЕМА УЧЕТА ОЦЕНОК СТУДЕНТОВ
=====================================

1. Добавить нового студента
2. Удалить студента
3. Добавить оценку студенту
4. Удалить оценку у студента
5. Просмотреть информацию о студенте
6. Показать всех студентов
7. Показать статистику класса
8. Найти лучшего студента
9. Сохранить в файл
10. Загрузить из файла
0. Выход

Выберите действие: _
```

#### **Логика каждого пункта:**

**1. Добавить студента:**
- Запросить имя
- Запросить название курса (или использовать default)
- Автоматически присвоить ID
- Подтверждение добавления

**2. Удалить студента:**
- Показать список студентов с ID
- Запросить ID для удаления
- Подтверждение действия
- Удаление или сообщение об ошибке

**3. Добавить оценку:**
- Запросить ID студента
- Проверить существование
- Запросить оценку (0-100)
- Валидация ввода
- Добавить и показать обновленный средний балл

**4. Удалить оценку:**
- Запросить ID студента
- Показать его оценки с индексами
- Запросить индекс для удаления
- Удалить и пересчитать средний балл

**5. Просмотреть студента:**
- Запросить ID
- Показать: имя, курс, все оценки, средний балл, буквенную оценку, min/max

**6. Показать всех:**
- Таблица: ID | Имя | Курс | Кол-во оценок | Средний балл | Буквенная оценка

**7. Статистика класса:**
- Средний балл класса
- Лучший студент (имя + средний балл)
- Худший студент
- Распределение: A: X, B: Y, C: Z...

**8. Лучший студент:**
- Найти студента с максимальным средним баллом
- Показать полную информацию

**9-10. Сохранение/загрузка:**
- Использовать текстовый формат или JSON
- Формат: одна строка на студента, оценки через запятую

### **6. Пример использования**

```cpp
int main() {
    GradeBook mathClass("Математика");
    
    // Добавляем студентов
    int id1 = mathClass.addStudent("Иван Петров");
    int id2 = mathClass.addStudent("Мария Сидорова");
    
    // Добавляем оценки
    mathClass.addGradeToStudent(id1, 85);
    mathClass.addGradeToStudent(id1, 92);
    mathClass.addGradeToStudent(id1, 78);
    
    mathClass.addGradeToStudent(id2, 95);
    mathClass.addGradeToStudent(id2, 88);
    
    // Показываем статистику
    mathClass.displayClassStatistics();
    
    return 0;
}
```

### **8. Частые ошибки и решения**

| Проблема | Решение |
|----------|---------|
| Деление на ноль при среднем балле | Проверять `grades.empty()` перед вычислением |
| Неверный ID студента | Всегда проверять результат `findStudent != nullptr` |
| Отрицательные оценки | Валидация в `addGrade`: `if (grade < 0 || grade > 100)` |
| Утечки памяти | Использовать векторы, избегать `new/delete` |
| Static ID сбрасывается | Инициализировать `int GradeBook::nextId = 1;` в .cpp файле |
